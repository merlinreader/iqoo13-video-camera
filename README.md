# iQOO 13 Видео · v0.1.0

Экспериментальная офлайн-видеокамера на Kotlin/Camera2 для iQOO 13.

**APK** появится в [Releases](https://github.com/merlinreader/iqoo13-video-camera/releases) только после успешной реальной CI-сборки и проверки подписи. Исходный проект полностью находится в `source.zip`.

## Физика камер

Официальные аппаратные данные: 1× Sony IMX921 50MP 1/1.56″ f/1.88, 2× Sony IMX816 50MP 1/2.93″ f/1.85, сверхширокая 50MP 1/2.76″ f/2.0. Источник: https://www.iqoo.com/in/products/param/iqoo13. У сторонних приложений нет гарантий доступа ко всем физическим модулям и штатным алгоритмам.

Практически: основная камера + 4K/30 + HEVC + стабилизация + EV 0 — стартовый вариант. 4K/60 требует достаточно света, меньшие матрицы теле/сверхширокой хуже в темноте. Шум, динамический диапазон, смаз/rolling shutter и пределы сенсора не исправить LUT.

## Реализовано в первой версии

Camera2 preview; MediaRecorder MP4/AAC; доступные 1080p/4K 30/60 при заявленной поддержке; H.264/HEVC; переключение открытых Camera2 ID; EV, AE/AWB lock, AF/manual focus; EIS или OIS; iPhone Look (экспериментальные аппаратные запросы, только SDR); MediaStore; диагностика с экспортом JSON, ISO/выдержкой/сенсором/OIS/EIS.

## Границы

HDR/10bit, точное соответствие iPhone 17 Pro Max, гарантированная работа EIS в 4K/60 и доступ ко всем физическим объективам не заявлены. Цвет и стабильность проверяются на самом устройстве. Тестовый APK подписан debug-ключом, не Play Store release certificate. Приложение не использует Интернет и не содержит отправки файлов.

## Установка

В [Releases](https://github.com/merlinreader/iqoo13-video-camera/releases) откройте `v0.1.0`, скачайте `iqoo13-camera-v0.1.0.apk`, установите с разрешением Android на установку из браузера. Выдайте доступ к камере/микрофону, запишите тестовое видео. Сохранение: Галерея → Фильмы → iQOO Camera.

## Сборка

Используется Java 17, Android SDK 35, Gradle 8.11.1, AGP 8.9.2, Kotlin 2.1.20. `unzip source.zip && gradle :app:assembleDebug`. CI запускается на единственном коммите, проверяет подпись и публикует APK только после успешной сборки.
